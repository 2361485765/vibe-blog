# 02 - 快速开始

## 2.1 环境要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | 3.10+ | 后端运行时 |
| Node.js | 18+ | 前端构建 |
| pip | 最新 | Python 包管理 |
| Git | 任意 | 代码版本管理 |

**最低硬件要求**：
- RAM: 2GB（开发）/ 4GB（Docker 生产部署）
- 磁盘: 500MB（不含生成产物）

## 2.2 获取源码

```bash
git clone https://github.com/datawhalechina/vibe-blog.git
cd vibe-blog
```

## 2.3 后端安装

### 创建虚拟环境

```bash
cd backend
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS/Linux
source .venv/bin/activate
```

### 安装依赖

```bash
pip install -r requirements.txt
```

`requirements.txt` 中的核心依赖包括：

| 包名 | 用途 |
|------|------|
| flask / flask-cors | Web 框架 |
| langgraph | Agent 工作流编排 |
| langchain-openai / langchain-google-genai | LLM 客户端 |
| jinja2 | Prompt 模板 |
| httpx / requests | HTTP 客户端 |
| python-dotenv | 环境变量管理 |
| pydantic | 数据模型校验 |
| oss2 | 阿里云 OSS（可选）|

## 2.4 配置 API 密钥

复制环境变量模板并填入你的 API 密钥：

```bash
cp .env.example .env
```

编辑 `.env` 文件，必须配置的最小集：

```env
# 🔑 必须：LLM 文本生成（阿里云 DashScope 兼容 OpenAI 格式）
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxx
OPENAI_API_BASE=https://dashscope.aliyuncs.com/compatible-mode/v1
TEXT_MODEL=qwen3-max-preview
```

可选但推荐的配置：

```env
# 联网搜索（智谱）
ZAI_SEARCH_API_KEY=xxxxxxxxxxxxxxx

# AI 图片生成（Nano Banana）
NANO_BANANA_API_KEY=xxxxxxxxxxxxxxx

# PDF 解析（MinerU）
MINERU_TOKEN=xxxxxxxxxxxxxxx
```

### 配置优先级

配置系统遵循以下优先级（高到低）：

1. **环境变量** `.env` → 覆盖默认值
2. **`config.py` 默认值** → 代码中的 fallback
3. **运行时检测** → 根据部署环境（Vercel/Docker）自适应

### 详细配置项说明

参考 `backend/.env.example` 文件，主要配置分组：

| 分组 | 环境变量 | 说明 |
|------|----------|------|
| LLM | `OPENAI_API_KEY`, `TEXT_MODEL` | LLM 核心配置 |
| 搜索 | `ZAI_SEARCH_API_KEY`, `SERPER_API_KEY` | 搜索引擎 API |
| 图片 | `NANO_BANANA_API_KEY` | AI 图片生成 |
| PDF | `MINERU_TOKEN` | PDF 解析服务 |
| OSS | `OSS_ACCESS_KEY_ID`, `OSS_BUCKET_NAME` | 阿里云 OSS |
| LLM 分层 | `LLM_FAST`, `LLM_SMART`, `LLM_STRATEGIC` | 三级模型策略 |
| 功能开关 | `HUMANIZER_ENABLED`, `FACTCHECK_ENABLED` | Agent 功能开关 |
| 追踪 | `TRACE_ENABLED`, `LANGFUSE_*` | Langfuse 可观测性 |

## 2.5 前端安装

```bash
cd frontend
npm install
```

## 2.6 启动应用

### 开发模式

**后端**（端口 5001）：

```bash
cd backend
python app.py
```

**前端**（端口 5173）：

```bash
cd frontend
npm run dev
```

访问 `http://localhost:5173` 即可看到界面。

### 验证运行

后端健康检查：

```bash
curl http://localhost:5001/health
# 返回: {"status": "ok", "service": "banana-blog"}
```

## 2.7 应用初始化流程

了解 `create_app()` 函数（`backend/app.py`）的初始化顺序有助于理解系统启动过程：

```
create_app()
│
├─ 1. 加载配置 (Config)
├─ 2. 设置 CORS
├─ 3. 创建输出目录
├─ 4. 初始化 LLM 服务 (init_llm_service)
├─ 5. 初始化图片服务 (init_image_service)
├─ 6. 初始化 OSS 服务 (init_oss_service)
├─ 7. 初始化视频服务 (init_video_service)
├─ 8. 初始化数据库 + 知识库 (init_db_service + init_knowledge_service)
├─ 9. 初始化文件解析 (init_file_parser)
├─ 10. 初始化搜索 + 博客服务 (init_blog_services)
├─ 11. 初始化任务队列 (TaskQueueManager + CronScheduler)
├─ 12. 初始化对话式写作 (WritingSessionManager)
├─ 13. 注册所有 Blueprint 路由
├─ 14. 初始化 vibe-reviewer（可选）
└─ 返回 Flask app 实例
```

这个顺序确保了依赖关系：LLM 服务先初始化，因为搜索服务和博客服务都依赖它。

## 2.8 首次生成

1. 在首页输入技术主题（如 "Python 异步编程入门"）
2. 选择文章类型（教程/问题解决/对比）
3. 选择文章长度（推荐初次使用选 **mini** 模式，约 2-5 分钟完成）
4. 点击"生成"按钮
5. 系统创建异步任务并跳转到生成页面
6. 通过 SSE 实时查看各阶段进度
7. 生成完成后可查看、下载 Markdown 文件
