# 01 - 项目概述与架构

## 1.1 项目定位

vibe-blog 是一个 **AI 驱动的多 Agent 长文博客自动生成系统**。用户只需输入一个技术主题，系统就能通过 10+ 个专业化 AI Agent 的协同工作，自动完成以下任务：

- 联网搜索背景资料
- 规划文章大纲
- 逐章撰写内容
- 生成代码示例
- 创建 Mermaid 图表和 AI 封面图
- 深度追问与质量审核
- 去 AI 味润色
- 最终 Markdown 组装输出

**核心特性**：

| 特性 | 说明 |
|------|------|
| 多 Agent 协同 | 基于 LangGraph 的 10+ Agent 流水线 |
| 多长度支持 | mini（800字）/ short（1500字）/ medium（3500字）/ long（6000字）|
| 联网搜索 | 智谱 / Serper / 搜狗三引擎自动路由 |
| 知识融合 | 支持 PDF/MD/TXT 文档上传，RAG 管线融合 |
| 质量控制 | 追问-深化循环 + 段落评估 + 质量审核 + 事实核查 |
| 实时进度 | SSE 流式推送，前端实时展示生成进度 |
| 多平台发布 | 支持 CSDN / 掘金 / 知乎 / 小红书 |

```

├──────────────────────────────────────────────┤
│          Agent 编排层 (LangGraph)              │
│   BlogGenerator / StateGraph / 中间件管道      │
```

## 1.5 设计决策

### 为什么选择多 Agent 架构？

单一 LLM 调用虽然更简单，但无法满足长文生成的质量要求。多 Agent 架构的优势：

1. **职责分离**：每个 Agent 有专属 Prompt，针对性优化
2. **迭代精炼**：通过 Questioner、Reviewer 等反馈循环自动提升质量
3. **模块可替换**：可以单独升级某个 Agent 而不影响其他
4. **可观测性**：清晰的阶段边界让进度追踪变得简单
5. **Prompt 管理**：`infrastructure/prompts/` 目录下的 Jinja2 模板降低了 Prompt 复杂度

### 为什么选择 LangGraph？

LangGraph 是 LangChain 团队推出的有状态 Agent 编排框架，相比原生 LangChain 或自建编排器：

- **状态管理**：`SharedState` 在 Agent 间自动传递和持久化
- **条件路由**：通过 `add_conditional_edges` 实现质量控制循环
- **检查点**：内置 `MemorySaver`，支持中断恢复
- **可观测性**：原生支持调用链追踪

### 为什么选择 SSE 而非 WebSocket？

- SSE 是单向通信（服务端 → 客户端），恰好满足进度推送需求
- SSE 基于标准 HTTP，与所有基础设施兼容
- 浏览器原生支持自动重连
- Vercel 无服务器部署支持 SSE 但不支持 WebSocket

### StyleProfile：统一风格配置

项目早期有 44 处 `if target_length == 'mini'` 的散落判断，`StyleProfile` 将所有行为参数收拢到一个 dataclass 中：

- **行为参数**：最大修订轮数、追问轮数、修订策略等
- **风格参数**：文风、配图风格、复杂度
- **Agent 开关**：事实核查、叙事一致性检查、去 AI 味等
- **预设套餐**：mini / short / medium / long 四个级别

## 1.6 端到端请求流

```
用户输入主题
    │
    ▼
POST /api/blog/generate   ← 前端发起请求
    │
    ├─→ TaskManager.create_task()  ← 创建异步任务
    │
    ├─→ 返回 { task_id }
    │
    └─→ 后台线程启动 BlogService.generate_blog()
           │
           ▼
         BlogGenerator.generate()
           │
           ├─ Researcher → 联网搜索 + 文档知识
           ├─ Planner → 生成大纲（可交互确认）
           ├─ Writer → 逐章撰写
           ├─ SearchCoordinator → 知识空白检测 + 补充搜索
           ├─ Questioner → 深度追问
           ├─ Writer → 内容深化
           ├─ Section Evaluate/Improve → 段落级优化
           ├─ Coder → 代码生成
           ├─ Artist → 配图生成（异步）
           ├─ CrossSectionDedup → 跨章节去重
           ├─ ConsistencyCheck → 叙事+语气一致性
           ├─ Reviewer → 质量审核
           ├─ FactCheck → 事实核查
           ├─ TextCleanup → 文本清理
           ├─ Humanizer → 去 AI 味
           ├─ Assembler → Markdown 组装
           └─ SummaryGenerator → SEO + 导读
           │
           ▼
         生成完成 → 保存到 outputs/

前端通过 GET /api/tasks/{task_id}/stream (SSE) 实时接收进度
```
