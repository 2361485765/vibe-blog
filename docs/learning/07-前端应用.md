## 7.4 核心页面

### Home.vue — 首页

博客生成的入口页面，包含：
- 主题输入框（支持 AI 优化主题）
- 文章类型选择（教程 / 问题解决 / 对比分析）
- 文章长度选择（mini / short / medium / long / custom）
- 目标受众选择
- 图片风格选择
- 文档上传区域
- 高级选项（深度思考、联网搜索、交互模式等）

### Generate.vue — 生成进度页

通过 SSE 实时展示博客生成进度：
- 阶段进度条（Researcher → Planner → Writer → ... → Assembler）
- 实时日志消息
- Markdown 预览（使用打字机效果逐步展示）
- 大纲确认交互（交互模式下）
- Token 使用量统计

### BlogList.vue — 博客列表

展示所有已生成的博客历史记录：
- 封面图缩略图
- 标题、生成时间
- 分页浏览
- 删除操作

### BlogDetail.vue — 博客详情

完整渲染已生成的博客：
- Markdown → HTML 渲染
- Mermaid 图表渲染
- 代码高亮
- 导出为 Markdown / 图片
- 多平台发布（CSDN、掘金、知乎）

## 7.5 API 服务层

**源文件**: `frontend/src/services/api.ts`

封装了与后端交互的所有 API 调用：

### 博客相关

```typescript
// 创建生成任务
createBlogTask(params: BlogGenerateParams): Promise<{task_id: string}>

// AI 优化主题
enhanceTopic(topic: string): Promise<{enhanced_topic: string}>

// 恢复中断的任务（大纲确认后）
resumeTask(taskId: string, action: 'accept' | 'edit', outline?): Promise<void>

// 获取历史记录
getBlogHistory(page, pageSize): Promise<HistoryResponse>

// 获取单条记录详情
getBlogDetail(id: string): Promise<{markdown: string, ...}>

// 删除历史记录
deleteBlogHistory(id: string): Promise<void>
```

### 请求参数类型

```typescript
interface BlogGenerateParams {
    topic: string
    article_type?: string           // tutorial / problem-solution / comparison
    target_length?: string          // mini / short / medium / long / custom
    target_audience?: string        // beginner / intermediate / advanced
    audience_adaptation?: string    // default / high-school / children
    document_ids?: string[]         // 上传的文档 ID
    image_style?: string            // 图片风格
    generate_cover_video?: boolean  // 是否生成封面视频
    deep_thinking?: boolean         // 是否启用深度思考
    background_investigation?: boolean // 是否联网搜索
    interactive?: boolean           // 是否交互模式
    custom_config?: {
        sections_count?: number
        images_count?: number
        code_blocks_count?: number
        target_word_count?: number
    }
}
```

## 7.6 SSE 实时进度

### useTaskStream 组合式函数

**源文件**: `frontend/src/composables/useTaskStream.ts`

核心功能：
1. 通过 `EventSource` 连接 `/api/tasks/{taskId}/stream`
2. 解析 SSE 事件，更新进度状态
3. 处理自动重连
4. 支持大纲确认交互

### SSE 事件类型

```typescript
// 进度事件
{
    type: "progress",
    stage: "researcher",     // 当前阶段
    progress: 25,            // 进度百分比
    message: "正在搜索背景资料..."
}

// LLM 流式事件
{
    type: "llm_stream",
    content: "...",          // 增量文本
    stage: "writer"
}

// 大纲确认事件
{
    type: "outline_confirm",
    outline: { title, sections, ... }
}

// 完成事件
{
    type: "completed",
    results: {
        markdown: "...",
        review_score: 85,
        token_summary: { ... }
    }
}

// 错误事件
{
    type: "error",
    message: "生成失败: ..."
}
```

## 7.7 Markdown 渲染

### useMarkdownRenderer

使用 `marked.js` 将 Markdown 转换为 HTML：
- 自定义渲染器处理代码块（高亮、复制按钮）
- 处理引用链接
- 支持打字机效果（逐步展示）

### useMermaidRenderer

处理 Markdown 中的 Mermaid 代码块：
- 检测 ````mermaid` 代码块
- 使用 Mermaid.js 渲染为 SVG
- 支持暗色/亮色主题切换

## 7.9 状态管理 (Pinia)

### blog store

管理博客生成相关的全局状态：
- 当前任务 ID
- 生成进度
- 历史记录缓存

### config store

管理应用配置：
- API 基础 URL
- 功能开关

### theme store

管理主题相关状态：
- 暗色/亮色模式切换

## 7.10 多平台发布

前端支持将生成的博客一键发布到多个平台：

| 平台 | 配置文件 |
|------|----------|
| CSDN | `publishers/configs/csdn.yaml` |
| 掘金 | `publishers/configs/juejin.yaml` |
| 知乎 | `publishers/configs/zhihu.yaml` |
| 小红书 | `publishers/configs/xiaohongshu.yaml` |

发布逻辑通过 `usePublish` composable 封装，调用后端发布 API。

## 7.11 小红书创作器

`XhsCreator.vue` 是一个独立的小红书内容创作工具，包含：
- 主题输入
- 图片生成（多图）
- 视频生成
- 文案生成
- 话题标签
- 预览和发布

通过 `composables/xhs/` 目录下的专用组合式函数实现。
