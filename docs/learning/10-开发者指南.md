## 10.2 添加新 Agent

### 步骤 1：创建 Agent 类

在 `backend/services/blog_generator/agents/` 下创建新文件：

```python
# agents/my_agent.py
import logging
from typing import Dict, Any

logger = logging.getLogger(__name__)

class MyAgent:
    def __init__(self, llm_client):
        self.llm = llm_client
    
    def run(self, state: Dict[str, Any]) -> Dict[str, Any]:
        """
        执行 Agent 逻辑
        
        Args:
            state: SharedState 字典
        Returns:
            更新后的 state
        """
        logger.info("=== MyAgent 执行中 ===")
        
        # 从 state 读取输入
        sections = state.get('sections', [])
        
        # 调用 LLM
        result = self.llm.chat([
            {"role": "user", "content": "你的 prompt"}
        ])
        
        # 更新 state
        state['my_output'] = result
        return state
```

### 步骤 2：在 SharedState 中添加字段

编辑 `schemas/state.py`：

```python
class SharedState(TypedDict):
    # ... 已有字段 ...
    my_output: Optional[str]  # 新增
```

在 `create_initial_state()` 中初始化：

```python
my_output=None,
```

### 步骤 3：注册到工作流

编辑 `generator.py`：

```python
# 导入
from .agents.my_agent import MyAgent

class BlogGenerator:
    def __init__(self, ...):
        # 初始化
        self.my_agent = MyAgent(_proxy('my_agent'))
    
    def _my_agent_node(self, state):
        return self.my_agent.run(state)
    
    def _build_workflow(self):
        # 添加节点
        workflow.add_node("my_agent", self.pipeline.wrap_node(
            "my_agent", self._my_agent_node
        ))
        
        # 添加边（将新节点插入到合适的位置）
        workflow.add_edge("previous_node", "my_agent")
        workflow.add_edge("my_agent", "next_node")
```

### 步骤 4：配置 LLM 级别

编辑 `llm_tier_config.py`：

```python

    # ... 已有映射 ...
    'my_agent': 'fast',  # fast/smart/strategic
```

## 10.4 编写 Prompt 模板

### Jinja2 模板语法

```jinja2
{# 注释 #}

{# 变量 #}
{{ topic }}

{# 条件 #}
{% if target_length == 'long' %}
请深入分析每个概念...
{% endif %}

{# 循环 #}
{% for concept in key_concepts %}
- {{ concept }}
{% endfor %}

{# 过滤器 #}
{{ content | truncate(500) }}
```

### Prompt 最佳实践

1. **角色定义**: 在 system prompt 中明确 Agent 的角色和能力边界
2. **结构化输出**: 要求 JSON 格式输出，便于程序解析
3. **示例驱动**: 提供 few-shot 示例
4. **长度控制**: 明确目标字数和章节数
5. **语言指定**: 明确要求中文输出

## 10.7 代码风格与约定

### 命名约定

- Agent 类: `XxxAgent`（如 `WriterAgent`）
- 服务类: `XxxService`（如 `LLMService`）
- 节点方法: `_xxx_node`（如 `_writer_node`）
- 条件路由: `_should_xxx`（如 `_should_deepen`）
- 环境变量: `UPPER_SNAKE_CASE`
- 版本标记: `# 37.xx:`, `# 102.xx:` 等注释

### 错误处理

- Agent 内部异常: 捕获并降级（不中断工作流）
- 服务层异常: 记录日志 + 返回错误信息
- LLM 调用: 通过 `resilient_llm_caller` 自动重试

### 功能开关模式

所有增强功能都遵循双开关模式：

```python
# 1. 环境变量全局开关
self._env_xxx = os.getenv('XXX_ENABLED', 'true').lower() == 'true'

# 2. StyleProfile 运行时开关
style = self._get_style(state)
if self._is_enabled(self._env_xxx, style.enable_xxx):
    # 执行功能
```
