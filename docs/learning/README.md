## 阅读建议

- **初次接触**：建议按 01 → 02 → 03 → 04 的顺序阅读，建立对项目的整体认知
- **深入开发**：重点阅读 05（服务层）、06（状态管理）、10（开发者指南）
- **部署运维**：重点阅读 02（配置）、09（部署）、08（API）
- **前端开发**：重点阅读 07（前端）、08（API）
