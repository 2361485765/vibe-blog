# 09 - 部署指南

## 9.1 部署选项概览

| 方式 | 场景 | 特点 |
|------|------|------|
| Docker Compose | 生产环境 | 完整功能、持久化存储、Nginx 反代 |
| Vercel | 无服务器 | 全球 CDN、自动扩缩、内存 SQLite |
| 本地开发 | 开发调试 | 最简单、实时热重载 |

## 9.2 Docker 部署（推荐生产方案）

### 架构

```
                    ┌─────────┐
                    │  Nginx  │ ← SSL 终端 + 静态文件
                    │  :80    │
                    └────┬────┘
                         │
            ┌────────────┼────────────┐
            │            │            │
     ┌──────▼──────┐  ┌──▼──────┐   │
     │  Frontend   │  │ Backend │   │
     │  (静态文件) │  │ :5001   │   │
     │  Nginx 托管 │  │ Flask   │   │
     └─────────────┘  └────┬────┘   │
                           │        │
                    ┌──────▼──────┐ │
                    │   SQLite    │ │
                    │   (volume)  │ │
                    └─────────────┘ │
                                    │
                    ┌───────────────▼┐
                    │  Persistent    │
                    │  Volumes:      │
                    │  - data/       │
                    │  - outputs/    │
                    │  - uploads/    │
                    │  - logs/       │
                    └────────────────┘
```

### docker-compose.yml

```yaml
version: '3.8'

services:
  backend:
    build:
      context: ../backend
      dockerfile: Dockerfile
    ports:
      - "5001:5001"
    volumes:
      - backend-data:/app/data
      - backend-outputs:/app/outputs
      - backend-uploads:/app/uploads
      - backend-logs:/app/logs
    env_file:
      - ../backend/.env
    restart: unless-stopped

  frontend:
    build:
      context: ../frontend
      dockerfile: ../docker/Dockerfile.frontend
    ports:
      - "80:80"
    depends_on:
      - backend
    restart: unless-stopped

  nginx:
    image: nginx:alpine
    ports:
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
    depends_on:
      - backend
      - frontend
    restart: unless-stopped

volumes:
  backend-data:
  backend-outputs:
  backend-uploads:
  backend-logs:
```

### Backend Dockerfile

```dockerfile
FROM python:3.10-slim

WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y --no-install-recommends \
    build-essential \
    && rm -rf /var/lib/apt/lists/*

# 安装 Python 依赖
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# 安装 Playwright（用于某些渲染功能）
RUN pip install playwright && playwright install chromium --with-deps

COPY . .

# 创建必要目录
RUN mkdir -p data outputs outputs/images uploads logs/blog_tasks

EXPOSE 5001

CMD ["python", "app.py"]
```

### Frontend Dockerfile

```dockerfile
# 构建阶段
FROM node:18-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 生产阶段
FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
COPY ../docker/nginx-frontend.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```

### Nginx 配置

```nginx
server {
    listen 80;
    server_name _;

    # 前端静态文件
    location / {
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://backend:5001;
        proxy_http_version 1.1;
        proxy_set_header Connection "";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 600s;  # 长超时支持 SSE
        proxy_buffering off;       # 关闭缓冲支持 SSE
    }

    # 健康检查
    location /health {
        proxy_pass http://backend:5001;
    }

    # 静态资源（生成的图片等）
    location /outputs/ {
        proxy_pass http://backend:5001;
    }
}
```

**关键配置说明**：
- `proxy_buffering off`: 必须关闭缓冲，否则 SSE 事件会被缓存而非实时推送
- `proxy_read_timeout 600s`: SSE 连接需要长时间保持，超时设为 10 分钟
- `try_files $uri $uri/ /index.html`: Vue Router 的 history 模式需要 fallback

### 部署步骤

```bash
# 1. 配置环境变量
cp backend/.env.example backend/.env
# 编辑 .env 文件

# 2. 构建并启动
cd docker
docker-compose up -d --build

# 3. 查看日志
docker-compose logs -f backend

# 4. 停止服务
docker-compose down
```

## 9.3 Vercel 无服务器部署

### 架构

```
浏览器 → Vercel Edge CDN → Serverless Function (api/index.py)
                              └→ Flask App (内存 SQLite)
```

### 入口文件

```python
# api/index.py
import sys
from pathlib import Path

project_root = Path(__file__).parent.parent
sys.path.insert(0, str(project_root))
sys.path.insert(0, str(project_root / 'backend'))

from backend.app import create_app
app = create_app()
```

### vercel.json

```json
{
    "buildCommand": "pip install -r backend/requirements.txt",
    "framework": "flask",
    "regions": ["sfo1"],
    "rewrites": [
        { "source": "/(.*)", "destination": "/api/index.py" }
    ]
}
```

### Vercel 部署限制

| 限制 | 说明 | 影响 |
|------|------|------|
| 函数超时 | 最长 60s（Pro 版 300s）| 长文生成可能超时 |
| 内存 | 1024MB | 大型文档处理受限 |
| 无状态 | 每次请求独立 | SQLite 数据不持久 |
| 无文件系统 | `/tmp` 临时目录 | 图片生成需要 OSS |

### 适用场景

- 短文（mini/short）生成
- 演示和试用
- 无需持久化历史的场景

## 9.5 持久化存储

### Docker 卷映射

| 卷名 | 容器路径 | 内容 |
|------|----------|------|
| `backend-data` | `/app/data` | SQLite 数据库 |
| `backend-outputs` | `/app/outputs` | 生成的 Markdown + 图片 |
| `backend-uploads` | `/app/uploads` | 用户上传的文档 |
| `backend-logs` | `/app/logs` | 日志文件 |

### SQLite 数据库

位于 `backend/data/` 目录下：

| 数据库 | 用途 |
|--------|------|
| `vibe_blog.db` | 主数据库（文档、历史、图片） |
| `task_queue.db` | 任务队列 |
| `writing_sessions.db` | 对话式写作会话 |

## 9.6 生产注意事项

### 性能优化

1. **并发控制**: `TaskQueueManager` 的 `max_concurrent=2` 限制同时执行的任务数
2. **LLM 限流**: `LLM_MIN_REQUEST_INTERVAL` 控制请求间隔
3. **图片异步**: 配图在后台线程生成，不阻塞文本处理

### 安全建议

1. 不要在代码中硬编码 API Key
2. 使用 `.env` 或 Docker secrets 管理敏感配置
3. 配置 CORS 白名单（`CORS_ORIGINS`）
4. 生产环境关闭 debug 模式（`FLASK_ENV=production`）

### 监控

1. 健康检查: `GET /health`
2. Langfuse 追踪: 设置 `TRACE_ENABLED=true`
3. 结构化任务日志: `logs/blog_tasks/` 目录
4. Token 用量追踪: SSE 事件中的 `token_summary`

### 备份

定期备份 Docker 卷中的数据：

```bash
# 备份 SQLite 数据库
docker cp vibe-blog-backend:/app/data ./backup/data

# 备份生成的内容
docker cp vibe-blog-backend:/app/outputs ./backup/outputs
```
